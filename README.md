# Cadastro de Produtos - Windows Forms

## Sobre o projeto
Aplicação desenvolvida em C# utilizando Windows Forms e Visual Studio para realizar o cadastro e gerenciamento de produtos.

## Tecnologias utilizadas
- C#
- Windows Forms
- Visual Studio

## Funcionalidades
- Cadastro de produtos.
- Geração simulada de códigos.
- Cálculo automático da margem de lucro.
- Validação dos dados.
- Controle de estoque inicial e mínimo.
- Limpeza dos campos.
- Simulação de exclusão de produtos.

## Observação
O projeto não utiliza banco de dados. A geração dos códigos dos produtos é simulada.

## Objetivo
Atividade acadêmica para praticar o desenvolvimento de interfaces gráficas, utilização de componentes da Toolbox e programação de eventos em C#.
